# 🌱 Soil Soothe – Smart Agriculture Web App

Soil Soothe is a modern smart farming web application built using React, TypeScript, Firebase, and Tailwind CSS. The project helps farmers monitor soil conditions, weather updates, crop information, irrigation systems, and real-time dashboard analytics.

This project focuses on improving agricultural productivity through technology-driven solutions.

---

# 🚀 Features

* 🌦️ Real-time weather monitoring
* 💧 Soil moisture tracking dashboard
* ⚡ Motor control status cards
* 🌾 Crop recommendation and crop details pages
* 📊 Interactive charts and analytics
* 🔔 Alert and notification panels
* 🌐 Multi-language support (i18n)
* 📱 Responsive UI for mobile and desktop
* 🔥 Firebase integration
* 🎨 Modern UI using Tailwind CSS + shadcn/ui

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/soil-soothe.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd soil-soothe
```

## 3️⃣ Install Dependencies

Using npm:

```bash
npm install
```

Or using bun:

```bash
bun install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```
